# Анализ задач из основного репозитория ReSDK_A3.vr

## Обзор проекта
ReSDK_A3.vr - это комплексный SDK для создания пользовательского контента к модификации Relicta на базе Arma 3. Проект включает:

- Исходный код проекта Relicta (клиент и сервер)
- WYSIWYG редактор ReEditor 
- Редактор визуального программирования ReNode
- Утилиту RBuilder для развертывания
- Компоненты ReBridge и ReEngine для скриптов на C#
