## 🎯 Использование

### **Из RBuilder (основной сценарий):**
```sqf
// Загрузка карты
["path/to/map.cpp"] call dml_loadMap;

// Валидация карты
["path/to/map.cpp"] call dml_validateMap;

// Миграция карты
["path/to/map.cpp", "1.1"] call dml_migrateMap;

// Пакетная обработка
["maps_folder", "validate"] call dml_batchProcessMaps;
```

### **Из редактора 3DEN:**
```sqf
// Виртуальная сборка текущей карты
[] call mm_virtualBuildCurrentMap;

// Валидация текущей карты
[] call mm_virtualValidateCurrentMap;

// Пакетная сборка всех карт
["build", createHashMap] call mm_virtualBatchProcessMaps;
```

### **Консольные команды:**
- `vbuild` - виртуальная сборка текущей карты
- `validate` - валидация текущей карты 
- `migrate` - миграция текущей карты
- `batch_build` - пакетная сборка всех карт
- `batch_validate` - валидация всех карт
- `batch_migrate` - миграция всех карт
