# Анализ задачи #422: Виртуальный сборщик карт

## Описание проблемы

**Текущая ситуация:**
- Для сборки каждой карты нужно её загружать в редактор, что крайне неудобно при текущем количестве карт
- Процесс сборки требует ручного вмешательства для каждой карты
- Нет возможности автоматической валидации всех карт при релизе

**Требуемое решение:**
- Загрузка карт напрямую из .cpp файлов (бинарных карт) без открытия в редакторе
- Виртуальная сборка и валидация всех существующих карт
- Автоматическая миграция версий карт

## Текущее состояние реализации

### ✅ Реализовано:
1. **Базовая структура виртуального сборщика** (`Maps_manager_virtualMap.sqf`):
   - `mm_virt_build()` - основная функция (пока заглушка)
   - `mm_virt_internal_loadMapConfig()` - загрузка конфигурации карты
   - `mm_virt_internal_cfgConvertClass()` - конвертация классов конфигурации

2. **Полноценная система сборки карт** (`Maps_manager_common.sqf`):
   - `mm_build()` - основная функция сборки
   - `mm_handleObjectSave()` - обработка каждого объекта
   - Система обработки позиций и поворотов объектов
   - Валидация данных объектов
   - Генерация итогового кода карты

### ❌ Нужно доработать:
1. **Конверторы позиций и поворотов в игровые значения**

3. **Система валидации карт**

## Ключевые проблемы для решения

### 1. Парсинг конфигурации карт
- Текущая функция `mm_virt_internal_loadMapConfig` использует `loadConfig`
- Нужно расширить для полного извлечения данных объектов
- Обработка всех типов объектов и их свойств

### 2. Конвертация координат
В текущей системе используются:
```sqf
_pos = getPosATL _obj;  // ATL позиция
_pos = getPosWorld _obj; // Мировая позиция для объектов с нестандартным vectorUp
```
Нужно реализовать виртуальные аналоги без реальных объектов.

### 3. Обработка поворотов
```sqf
_vdir = getDir _obj;     // Направление
_vup = vectorUp _obj;    // Вектор вверх
__probNewDir = vectorDir _obj; // Направляющий вектор
```
Требуется виртуальная конвертация из данных конфигурации.

### 4. Валидация без загрузки
- Проверка существования классов объектов
- Валидация свойств и параметров
- Проверка ссылок между объектами
- Обнаружение конфликтов имен и маркеров
